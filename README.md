# Практика №3 — Клоков Иван Николаевич, ЭФБО-07-26

Технологии индустриального программирования. Два задания, каждое решено 4 способами:

1. **1_odna_funkciya** — всё решение в одной функции `main()`
2. **2_neskolko_funkciy** — решение разбито на функции (один файл)
3. **3_neskolko_failov** — решение разбито на несколько файлов (`.h` / `.cpp`)
4. **4_oop** — решение через класс (ООП)

## Задание 1. Гипотенуза треугольника

Даны два катета `a` и `b`. Найти гипотенузу `c = sqrt(a^2 + b^2)`.

Папка: [`Задание_1_Гипотенуза`](./Задание_1_Гипотенуза)

## Задание 2. Цифра десятков числа

Дано неотрицательное целое число `n`. Найти цифру десятков в его десятичной записи.

Папка: [`Задание_2_Цифра_десятков`](./Задание_2_Цифра_десятков)

## Сборка

Способы 1 и 2 — один файл:

```
g++ main.cpp -o program
```

Способы 3 и 4 — несколько файлов, например:

```
g++ main.cpp hypotenuse.cpp -o program   # Задание 1, способ 3
g++ main.cpp Triangle.cpp -o program     # Задание 1, способ 4
g++ main.cpp tens.cpp -o program         # Задание 2, способ 3
g++ main.cpp NumberInfo.cpp -o program   # Задание 2, способ 4
```
